# 应用图标

2026-10-23 采用用户确认的黑灰细线款：不透明的近白色连续圆角底板，搭配黑色编织绳结和右下分段额度仪表盘。仪表盘沿绳结回环延伸，各段由黑到浅灰过渡。保留确认稿的细线比例与交织负空间，不再使用早期的紫色六孔环或中心双条设计。

- 母图画布：1024 × 1024 RGBA；主体从 (100, 100) 到 (924, 924)，轮廓外透明，底板内部不透明。
- 底板 `#FCFCFD`，绳结纯黑 `#000000`，仪表盘使用中性黑灰序列。PNG 在 sRGB 色彩空间渲染，与 SVG 的颜色保持一致。
- 从确认稿固化平滑的矢量轮廓，并清除生成图中的背景纹理。图标采用纯色形状，不使用玻璃、高光、投影、浮雕或粒子；灰阶变化仅用于表达额度仪表盘。
- 32 像素下核对绳结交织、仪表盘间隔与灰阶；16 像素下以整体轮廓为主。仪表盘是静态功能标识，不代表当前实时额度。
- `AppIcon-shapes.json` 保存固定轮廓与灰阶数据，`render-icon.swift` 使用这些矢量几何同源输出 `AppIcon.svg` 和 `AppIcon.png`，正式构建不依赖原始生成图片或额外图像处理工具。
- `AppIcon-reference.png` 保存用户确认的原始设计图，用于核对造型与细线比例，不参与应用运行或正式渲染。
- `AppIcon.icns` 包含 16、32、128、256、512 点的 1x／2x 表示。当前 AppKit 应用使用静态 ICNS。

执行 `./Mac/Codings/build-icon.sh` 会先重新渲染母图与 SVG，再生成全部标准尺寸和 ICNS；执行 `./Mac/Codings/build-mac.sh` 将新图标复制到应用中并签名。仅需 Xcode Command Line Tools，不依赖 Icon Composer 或完整 Xcode。

最终图标由原生矢量与 Core Graphics 精确绘制，保证扁平造型和干净透明边缘；底板内部始终不透明。
